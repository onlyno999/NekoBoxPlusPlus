# 下载

到 GitHub 发布页下载最新版：

**[GitHub Releases](https://github.com/onlyno999/NekoBoxPlusPlus/releases/latest)**

当前版本：**1.4.3**

## 选哪个文件

每个版本会发布多个安装包，按需选一个即可：

| 文件名 | 说明 |
| --- | --- |
| `NekoBox-<版本>-arm64-v8a.apk` | 现在的安卓手机基本都是这个 |
| `NekoBox-<版本>-armeabi-v7a.apk` | 老款 32 位手机 |
| `NekoBox-<版本>-x86_64.apk` | 模拟器 |
| `NekoBox-<版本>-x86.apk` | 老款模拟器 |

文件名带 `-fdroid`、`-play`、`-preview` 的是同版本的其他渠道包，普通用户装不带后缀的即可。

## 安装说明

- 覆盖安装即可升级，不用卸载，配置和订阅都保留
- NekoBox++ 是独立包名，可与官方 NekoBox 同时存在
- 软件内「关于 → 检查正式版更新」也可以直接查到新版本
